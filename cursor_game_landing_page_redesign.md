## 🏗 Pitivi Architecture

Pitivi relies on the following technologies, which you should be familiar with:

 * [GStreamer](http://gstreamer.freedesktop.org/data/doc/gstreamer/head/manual/html/index.html), a
   multimedia framework. This is where most of the magic happens. Pitivi relies on
   [GES](http://gstreamer.freedesktop.org/data/doc/gstreamer/head/gstreamer-editing-services/html/),
   the GStreamer Editing Services library.
 * [GTK](http://www.gtk.org), a widget toolkit for graphical interfaces.

 * [Python](http://docs.python.org/3/), the programming language (version 3).

## Communication
For any question, send an email to our [mailing list](https://lists.freedesktop.org/mailman/listinfo/pitivi-general).

(http://gstreamer.freedesktop.org/data/doc/gstreamer/head/gstreamer-editing-services/html/)

the latest GTK through GObject Introspection. The GObject Introspection-based
approach will mean Pitivi will use a modern GTK stack and will be more
maintainable going forward.
